PHASE 02 · SCOPE & ROOT CAUSE

Status Quo vs. Project Aim

Why existing detection workflows fail early containment and setting a pragmatic edge software scope.

CURRENT STATUS QUO (SQ)
Existing Detection Bottlenecks
•
911 Calls Lag: 30–60 min delay before human sighting reaches dispatch.
•
Satellite Orbit Gap: 3–6 hr revisit cycles & frequent cloud occlusion.
•
Zero Cloud Access: Steep canyon terrain severs cellular signals during fires.
PROJECT AIM & SCOPE
Grounded Software Objective
•
<35MB Footprint: Fits within strict micro-device RAM limits.
•
Sub-15ms Inference: Instant on-device classification without internet.
•
Binary Smoke Detection: Dedicated classifier instead of complex drone overhauls.

“Grounded Scope: Build a fast, lightweight software classifier to verify smoke in aerial frames locally — keeping compute small enough for real-time edge devices.”
