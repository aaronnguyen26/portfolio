# Field Journal: Personal Website

A personal website styled as a leather-bound field journal: cream dot-grid paper, serif display type, handwritten notes, taped polaroids, and cardinal/gold accents.

Built with Next.js 16 (App Router), TypeScript and plain CSS (`src/app/globals.css`).

## Pages
Home, About, Projects, Writing, Contact.

## Edit content
All text is placeholder. Edit [`src/data/site.ts`](./src/data/site.ts) (name, links, projects, essays, timeline) and replace `public/resume.pdf`.

## Run
```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Deployed on Vercel (project already linked via `.vercel`).
